# Schedule (임시 이름) 다운로드

Windows용 데스크톱 위젯 설치 파일을 올리는 저장소입니다. 코드는 이 저장소에 없습니다.

## 설치
1. [Releases](../../releases/latest)에서 `Schedule-Widget_*_x64-setup.exe` 를 받습니다.
2. 실행합니다. 서명이 없어서 Windows SmartScreen 이 "알 수 없는 게시자"라고 알릴 수 있습니다. **추가 정보 → 실행**을 누르면 됩니다.
3. 소형 위젯에서 Google 또는 Kakao 로 로그인합니다.

## 참고
- 위젯은 일정을 보여주기만 하는 읽기 전용입니다. 일정은 웹이나 연결한 Claude 로 관리합니다.
- 큰 화면(기본 보기)은 웹 서비스를 창에 띄웁니다.
- Windows 10/11 (64비트)
